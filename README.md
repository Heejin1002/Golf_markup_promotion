# 📊 Golf Markup Calculator

골프 요금표 HTML을 기반으로 **판매가 / 공급가 / 마진 자동 계산 및 관리**를 지원하는 Streamlit 기반 내부 툴입니다.

---

## 🚀 주요 기능

- HTML 요금표 자동 파싱
- 플랫폼별 마크업 계산 로직 지원
- 마진 자동 보정 (음수 방지)
- 복수 요금표 비교 (증감률 계산)
- Google Sheets 자동 내보내기
- 수동 수정 시 자동 재계산

---

## 🧩 지원 플랫폼

### 1. 마이리얼트립 (마리트 골프)

#### ✅ 필터 조건
- 18H, 36H만 처리 (27H 제외)
- Morning / Afternoon만 처리 (Night 제외)

#### 💰 요금 구성
- 패키지넷(฿) = 그린피(넷) + 캐디피(넷) + 카트피(넷)
- 패키지세일(฿) = 그린피(세일) + 캐디피(세일) + 카트피(세일)
- 판매가(₩) = 패키지세일 × 환율

#### 📈 마진 계산
- 공급가 = 판매가 × (1 - 수수료율)
- 마진 = 공급가 - 패키지넷
- 마진 < 0 → 목표 마진율 기준으로 판매가 자동 상향

#### 🔄 증감률 계산
- 요금표 2개 입력 시 자동 비교
- 계산식:
  (최신 판매가 ÷ 이전 판매가 - 1) × 100
- 기준: 홀 / 시간대 / 주중·주말 매칭
- Google Sheet:
  - Y열 → 판매가 증가율 자동 입력

#### ⚙️ 상태
- ✅ 구현 완료

### 3. 트리플 골프

#### ✅ 필터 조건
- 없음 (전체 데이터 처리)

#### 💰 핵심 계산식
최소 마진 세일(฿) = 패키지넷 ÷ (계수 × (1 - 수수료율))

- 기본값
  - 계수: 0.89
  - 수수료: 5%

#### 💱 이중 환율 구조
- 몽키 환율 → 패키지넷 원화 변환
- 트리플 환율 → 공급가 계산 (기본 45.0)

#### 📈 계산 로직
- 트리플 공급가(₩)
  = 최소 마진 세일 × 트리플 환율 × (1 - 수수료)
- 마진(₩)
  = 트리플 공급가 - 패키지넷

#### 📊 출력 컬럼 (22개)
- 홀 / 시간대 / 주중·주말
- 그린피 / 캐디 / 카트 (넷/세일)
- 포함 여부
- 몽키 넷 / 세일
- 트리플 세일 / 최소 마진 세일
- 공급가 / 마진 / 환율 등

#### ⚙️ 상태
- ✅ 구현 완료
